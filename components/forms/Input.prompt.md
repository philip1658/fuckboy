Text field with condensed uppercase label and a sunken well.

```jsx
<Input label="Dein ehrlicher Satz" placeholder="Ich suche gerade …" hint="Ein Satz. Keine Erklärung." />
<Input label="Code" mono icon="lock" error="Falsches Aktenzeichen." />
```

Focus draws a volt border; errors draw bordeaux and swap the hint. Use `mono` when the input represents typed evidence.
