Chapter index row — the main navigation object of the product.

```jsx
<ChapterCard number="03" title="Der grösste Fehler" duration="14 Min" decisions={6}
  summary="Warum das Bedürfnis nach Sex der schnellste Weg ist, ihn nicht zu haben." />
<ChapterCard number="07" title="Was übrig bleibt" state="locked" bonus />
```

Numbers are always two digits in tabular mono: bordeaux when open, volt when done, faint when locked. `bonus` puts the row on bordeaux-900 for hidden files.
