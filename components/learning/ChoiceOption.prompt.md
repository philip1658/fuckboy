The core interaction of the product: a plausible answer whose consequence appears only after committing.

```jsx
<ChoiceOption letter="B" label="Du sagst" selected revealed outcome="costly"
  quote="„Ich weiss noch nicht, was daraus wird. Mal schauen.“"
  feedback="Taktisch wirksam. Erzeugt aber eine Hoffnung, die du nicht einlösen willst." />
```

Never write an option that is obviously correct. Set `outcome` to `costly` for the tactically effective but dishonest move — that ambiguity is the whole lesson. Unpicked options fade to 55% on reveal.
