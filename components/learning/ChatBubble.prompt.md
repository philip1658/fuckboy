Chat-simulation message. The learner's bubble is paper (inverted); hers is ink with a hairline.

```jsx
<ChatBubble from="her" time="23:38">Und was suchst du so?</ChatBubble>
<ChatBubble from="me" time="23:41" status="read">Ehrlich? Aktuell nichts Festes.</ChatBubble>
<ChatBubble from="her" typing />
```

Only the tail corner is squared (2px) — the rest is 10px. Read receipts use wire, not volt.
